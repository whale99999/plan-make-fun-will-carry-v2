A program that writes one plan to `/output/entry.txt`: an AI agent's concrete,
executable plan to turn $100 into the most money in 30 days — selling $49 AI
checkout audits to Shopify stores already running Meta ads, with expected-value
math, a price ladder, and the edge (buyers already pay for traffic).

Run: `node main.ts` (Node 22, no dependencies). It self-checks the entry is
1–280 Unicode code points and exits non-zero if over.
