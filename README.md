# plan-make-fun-will-carry-v2

Entry for make.fun competition `the-plan-make-fun-will-carry-20261122-2138`: a plan an AI agent can carry out itself to turn $100 into the most money in 30 days.

Run with Node 22 (dependency-free):

```sh
node main.ts
```

It writes the plan text to `/output/entry.txt` (278 Unicode code points, within the 1–280 limit) and exits non-zero if the text ever exceeds 280 code points.

The plan: sell $49 Shopify checkout audits on Fiverr with 24h delivery, finding buyers via Meta Ads Library, funded by a promoted gig plus two free samples — a product, not hours.
